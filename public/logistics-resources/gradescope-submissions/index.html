Submitting Assignments on Gradescope

January 8, 2026 · Danny Caballero, Morten Hjorth-Jensen, Rachel Henderson, Alia Valentine

All of your assignments except for the final project will be submitted through Gradescope. This platform allows you to submit your homework online, and to view your graded assignments and feedback.

To make it easier for you and for the graders, we would like you to follow the instructions below.

  1. Scan your handwritten solutions into one .pdf file and save that file onto your computer.

  2. Convert your Jupyter notebook into a .pdf file by doing the following:

    a. Select File then Download As HTML (.html).

    b. Open the .html file using your web browser. This should bring up your code.

    c. On your web browser, select File then Print.

    d. In the Destination, select Save As PDF and save it in the same location as your handwritten solutions.

  3. Combine your handwritten .pdf and your notebook .pdf by doing the following:

    a. Open your handwritten solutions file. Select View then Thumbnails. This should bring up all your scanned solutions on the left-hand side.

    b. In the Thumbnail section, scroll and click on the last page of your scanned solutions.

    c. Select Edit then Insert then Page from File.

    d. Find and select your notebook .pdf. This should add the file below your handwritten solutions.

    e. Save the new file as _combined.pdf.

  4. Upload the _combined.pdf to your Gradescope submission.
